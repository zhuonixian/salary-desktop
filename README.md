# Salary Desktop - 工资核算助手

给中小微企业出纳、财务、人事的**本地单机一体化桌面工具**：从工资核算到发票报销、资金出纳、自动记账、三大报表、办税辅助，全程在本机完成，数据不出本机（仅发票 OCR 与邮件通知为可选外联）。

## 功能特性

### 薪酬核心
- **员工与考勤** — 员工档案 Excel 导入导出；月度考勤导入；打卡表 OCR 识别（百度 API / 本地 PaddleOCR）
- **工资核算** — 社保公积金、个税累计预扣、考勤扣款一键计算；单人重算；月度锁定；个税年度汇总；工资条打印与邮件直发（SMTP 授权码加密）

### 发票与报销
- **进项发票** — OCR 录入、全电票去重、原图加密归档、报销关联门禁、进项台账
- **销项发票** — 销售开票登记，自动生成收入确认凭证（借应收 / 贷收入 / 贷销项税）
- **报销管理** — 审批流、经办复核、反审批、付款联动

### 资金出纳
- **资金账户与收付款单** — 收 / 付 / 转账 / 借款单据审批留痕、红字冲正、加密附件
- **付款批次** — 工资 / 报销 / 通用批次统一导出银行代发文件
- **银行对账** — 流水导入、多对多核销工作台、余额调节表
- **资金日记账 / 资金日报** — 按账户收支明细与滚动余额
- **票据台账** — 承兑 / 支票登记，背书、贴现、托收、兑付全状态机与凭证联动
- **应收台账** — 销项核销进度、账龄五档分桶、回款多对多部分核销
- **现金盘点 / 借款备用金** — 面额明细盘点差异凭证；借款三方式核销与账龄

### 会计核算
- **科目表与期初** — 62 个预置科目（小微企业准则）、借贷平衡期初录入
- **自动凭证** — 16 类凭证来源：工资计提 / 代发、报销、发票、银行流水、资金单据、票据、盘点、销项、固定资产、年末结转等业务动作自动生成、作废自动红冲
- **手工凭证** — 收 / 付 / 转三类，资金科目行强制关联资金账户，借贷实时平衡
- **固定资产** — 登记购置凭证、月度直线折旧（聚合一张凭证）、处置净损益自动结转、台账导出
- **三大报表** — 资产负债 / 利润 / 现金流量 + 科目余额表 + 同期对比，Excel 导出

### 办税与提醒
- **申报模板** — 个税扣缴端人员信息采集 / 工资薪金导入模板（列序对齐扣缴端）、社保基数年度申报表
- **征期日历** — 五类征期提醒、完成留痕；个税扣缴申报表导出
- **提醒触达** — 征期 / 账期 / 月结 / 备份四源聚合 OS 系统通知（每日去重、正文不含金额）+ 托盘常驻待办角标

### 数据安全
- **三层密码体系** — 启动密码（Argon2id + KEK/DEK）→ 闲置锁屏 → 敏感数据二次解锁（5 分钟）
- **静态加密** — 发票原图 AES-GCM-256 就地加密归档；备份包可选加密；SMTP 授权码 / OCR token 加密入库
- **数据安全中心** — 备份 / 恢复 / 体检 / 压缩；全量操作审计日志
- **全局脱敏** — 金额、证件号等敏感字段默认星号，解锁后限时明文

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | React 19 + TypeScript + Ant Design 6 + Vite |
| 后端 | Tauri 2 (Rust) + SQLite (rusqlite) |
| Excel | rust_xlsxwriter（导出）/ calamine（导入） |
| OCR | 百度 vat_invoice + 通用 OCR / 本地 PaddleOCR sidecar |

## 下载与安装

从 [Releases](https://github.com/zhuonixian/salary-desktop/releases) 下载 Windows / macOS（Apple Silicon）/ Linux 安装包，或使用网盘链接（见用户手册）。

- **Windows**：首次运行会被 SmartScreen 拦截（应用未购买代码签名证书），按 [Windows 首次安装指南](docs/windows-install-guide.md) 操作即可
- **macOS**：首次打开需右键 →「打开」绕过 Gatekeeper
- **完整用户手册**：[docs/user-guide-v2.html](docs/user-guide-v2.html)（含快速开始、各模块详细操作与常见问题）

## OCR 配置

- **在线模式**：在应用设置中填入百度云 OCR API Key 和 Secret Key
- **本地模式**：需要安装 Python 3 及 PaddleOCR 依赖（见 `python-ocr/` 目录），完全离线

## 开发

```bash
npm install                              # 安装前端依赖
npm run tauri dev                        # 开发模式（热重载）
npm run tauri build                      # 打包发布
cd src-tauri && cargo test --lib         # 后端单元测试
npx tsc -b                               # 前端类型检查
npm run lint                             # ESLint
```

数据存储在本地 SQLite 单文件（`salary.db`，位于系统应用数据目录），无任何云端依赖。
