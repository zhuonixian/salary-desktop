# 第五阶段：财务专业功能（科目表与三大报表）

完整计划：`docs/superpowers/plans/2026-08-15-stage5-accounting-reports.md`
spec：`docs/superpowers/specs/2026-08-15-stage5-accounting-reports-design.md`
进度同步：`docs/superpowers/plans/2026-08-15-stage5-progress.md`

## 定位

在第三/四阶段基础上补齐财务专业能力：预置《小企业会计准则》科目表、业务数据自动派生复式记账凭证（方案 A：凭证落库、报表实时汇总）、资产负债表/利润表/现金流量表与 Excel 导出。不做手工记账、多级明细科目、期末结转凭证。

## 已交付能力

1. 科目表：62 预置一级科目（可停用/可新增自定义），五大类 + 现金流量分类
2. 期初余额：选定启用月逐科目录入，保存校验借贷平衡
3. 映射：`account_mappings(scope,key)` 泛化设计（费用类型→科目、部门→科目），未配置回退 6602
4. 自动凭证：工资计提/工资代发、报销计提/报销付款、发票费用、银行流水手工凭证（bank_manual）六类业务事件
5. 防重复：发票只入一次账、已匹配流水不生成凭证、已入账流水禁止匹配付款批次、部分唯一索引 `(source_type,source_id) WHERE status='active'`
6. 作废联动：解锁/作废/反审批同事务 void 对应凭证，重新满足条件重新生成
7. 月结检查新增"记账凭证平衡"项
8. 三大报表实时汇总（未分配利润两表衔接、现金流量按对方科目分类、未归类明细提示）
9. 三报表 Excel 导出（rust_xlsxwriter）
10. 前端"财务管理"菜单组：科目表 / 记账凭证 / 财务报表；银行流水页未匹配行"生成凭证"入口

## 批次划分

- 批次一（Task 1-4）：5 表 DDL + 预置科目、CRUD、命令、科目表页面
- 批次二（Task 5-9）：凭证核心、工资/付款/报销/发票挂接、银行流水凭证 + 月结检查
- 批次三（Task 10-11）：三大报表计算引擎、命令与 Excel 导出
- 批次四（Task 12-14）：记账凭证页、财务报表页、银行流水生成凭证入口 + 全量回归 + 文档

## 不做范围（未来增强池）

- 手工记账凭证（收/付/转录入）、多级明细科目、期末结转损益凭证
- 上年同期对比、凭证/账簿打印
- 现金流量表本年累计列（引擎无累计计算，表头恒 0）

## 已知边界

- **工资月锁定不可逆（有意行为）**：`unlock_salary_results` 后端函数未暴露为 Tauri 命令/UI 入口——锁定不可逆、accrual 凭证不可作废是设计决定，防止已入账/已月结月份的工资数据被静默改写；是否暴露留待下一阶段决策。
- **存量数据报表为 0 属预期**：启用月之前或无凭证期间的存量数据不会出现在报表滚入窗口中（启用月之前的 0 是预期值），Windows 验收时不要误判为 bug；历史发票不会自动补凭证，仅新生成的业务事件入账。
