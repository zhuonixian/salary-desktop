产品简介
了解工资核算助手的核心能力与适用场景
🎯产品定位

工资核算助手是一款面向中小微企业的本地单机桌面工具，帮助出纳独立完成员工管理、考勤统计、工资核算、发票去重、报销付款、月结打包、银行流水匹配等全流程工作。所有数据存储在本地，不上云、不联网（仅调用百度 OCR 时联网），最大程度保护企业薪酬隐私。

快速开始
从安装到首月工资核算的完整引导
⚙️系统要求
  • 操作系统：Windows 10 / 11（64 位）；支持 macOS / Linux（需自行编译）
  • 磁盘空间：≥ 500 MB（含发票图片归档）
  • 内存：≥ 4 GB
  • OCR（可选）：百度智能云账号（用于发票 / 考勤 OCR）；本地 PaddleOCR（考勤 OCR 离线方案）
📦安装步骤
下载安装包 从内部 release 渠道获取 salary-desktop_0.4.x_x64-setup.exe，约 5.2 MB
双击运行安装程序 如 Windows SmartScreen 蓝色拦截 → 点「更多信息」→ 点「仍要运行」（应用未购买代码签名证书，首次运行需手动绕过）
选择安装目录 默认安装到 C:\Users\<用户>\AppData\Local\salary-desktop\，可改任意目录
启动应用 桌面图标「工资核算助手」双击启动；首次启动会引导你设置启动密码
⚠️ 注意 未签名 Windows 构建的 SmartScreen 拦截是正常现象，应用本身没有病毒。详细绕过指南见 docs/windows-install-guide.md
🚀首月工资核算流程

从零开始到第一次发放工资，建议按以下顺序操作：

初始化密码：首次启动设置启动密码 + 恢复码 + 安全问题
配置工资规则：菜单「系统设置」→ 调整社保比例、起征点、扣款标准、个税税率表
导入员工档案：菜单「人员考勤 → 员工管理」→ 下载模板 → 填写 → 批量导入
录入月度考勤：菜单「考勤管理」→ Excel 导入或「打卡表管理」拍照 OCR
计算工资：菜单「工资计算」→ 选择月份 → 点「一键计算」
审核与调整：核对计算结果，必要时点「单人重算」或手工调整
锁定工资：核对无误后点「锁定」，防止误改
生成付款批次：菜单「薪酬核算 → 付款批次」→ 生成工资批次 → 导出银行代发 Excel
月度关账：菜单「月结工作台」→ 体检 → 正式月结 → 导出月结包

安全配置 v0.4.x 新增
启动密码、锁屏、加密、脱敏四大防线
🔑 重要：必须妥善保存恢复码 首次启动应用会强制设置启动密码 + 恢复码 + 安全问题。恢复码丢失 + 忘记密码 + 忘记安全问题答案 = 数据永久无法恢复。请将恢复码抄写到纸张或密码管理器中。
🔐三层密码体系
层级触发解锁时长说明
① 启动密码每次启动应用整个使用期间≥8 位含字母 + 数字
② 锁屏闲置 5 分钟（可配）/ 手动锁屏重新输密码防止他人趁你离开时偷看
③ 敏感数据解锁点击身份证号 / 工资金额等小眼睛5 分钟（可配）解锁后全应用明文显示；到期自动恢复脱敏
🛡️敏感数据加密

以下数据使用 AES-256-GCM 加密存储，即使他人拿到电脑也无法直接读取：

  • 发票图片：归档时加密落盘
  • 备份包：导出时可勾选加密
  • 百度 OCR Token：API 凭证加密入库
ℹ️ 不加密项 数据库（salary.db）主体不加密，保证查询性能。身份证号、银行卡号等通过界面脱敏展示（中段打码），点小眼睛 + 输启动密码才能临时看明文。

🔄找回密码

忘记启动密码？提供两条找回路径：

🎫
恢复码（推荐）
首次设置时生成的 24 字符字符串（如 AAAA-BBBB-CCCC-DDD-EEEE-FFFF），在锁屏界面点「忘记密码」→「恢复码」Tab 粘贴
❓
安全问题
首次设置时选择的问题（如「你小学班主任姓什么」），输入答案 + 新密码即可重置
❌ 失败次数限制 密码错误 5 次锁定 5 分钟；恢复码 / 安全问题错误 3 次锁定 15 分钟。防止暴力破解。
🛠️安全中心

菜单「系统设置 → 安全中心」提供：

  • 改密码：输入原密码 + 新密码
  • 闲置锁定配置：开关 + 时长（1 / 5 / 15 / 30 分钟）
  • 敏感解锁时长：1 / 5 / 15 / 30 分钟
  • 手动锁屏：临时离开时一键锁定
  • 状态查看：失败尝试次数、上次改密时间

员工档案、月度考勤、打卡表 OCR
👥员工管理

路径：菜单「人员考勤 → 员工管理」

下载模板：点「下载模板」获取 员工导入模板.xlsx
填写员工信息：必填工号、姓名、身份证号、入职日期、基本工资；可选银行账号、社保公积金基数等
批量导入：点「Excel 导入」→ 选择文件 → 自动校验 → 错误提示逐行修改
手工新增 / 编辑：单员工场景直接点「新增」填写表单
导出：点「Excel 导出」生成当前员工清单
ℹ️ 工号规则 工号唯一且不可重复；建议用「部门缩写 + 序号」如 FIN-001。已离岗员工用「状态 = 离职」保留档案，不要删除（影响历史工资追溯）。
📅考勤管理

路径：菜单「人员考勤 → 考勤管理」

按月份维护每位员工的考勤数据：应出勤天数、实际出勤、迟到早退次数、加班时长、请假天数等。

选择月份：右上角月份选择器
Excel 导入：模板含员工工号 + 各考勤项列；导入时自动按工号匹配员工
手工调整：点员工行进入编辑，逐项修改
异常提示：实际出勤 > 应出勤、加班为负数等情况自动标红
📷打卡表 OCR

路径：菜单「人员考勤 → 打卡表管理」

支持把纸质打卡表 / 钉钉考勤截图直接 OCR 识别为结构化考勤数据。

☁️
百度在线 OCR
需要百度智能云账号；识别速度快、准确率高；按调用次数计费
💾
本地 PaddleOCR
完全离线，无外部依赖；首次启动需安装 Python 依赖；适合隐私敏感场景
ℹ️ OCR 配置 菜单「人员考勤 → OCR 识别中心」可切换百度 / 本地模式、配置百度 API Key。Token 自动加密缓存，110 错误时自动刷新一次。

工资核算
规则配置、一键计算、单人重算、锁定导出
📐工资规则配置

路径：菜单「系统设置 → 工资规则」

规则项说明示例
社保比例养老 / 医疗 / 失业 / 工伤 / 生育，个人与公司分别配置养老个人 8%、公司 16%
公积金比例个人与公司分别配置，可设上下限各 12%，上限 25201 元
个税起征点累计预扣预缴税率计算5000 元 / 月
七级超额累进税率国家标准税率表，可按年度更新3% / 10% / 20% ...
扣款标准迟到、早退、旷工每次扣款金额迟到 30 分钟扣 50 元
⚡一键计算工资

路径：菜单「薪酬核算 → 工资计算」

选择月份：右上角选择需要计算的月份
一键计算：点「一键计算」按钮，引擎读取全员考勤 + 规则，自动算出应发 / 社保 / 公积金 / 个税 / 实发
查看结果：表格展示每位员工明细；点击员工行进入详情
单人重算：发现某员工数据异常，修改考勤后点该员工的「重算」按钮（不影响其他人）
手工调整：补贴 / 扣款项可在「其他补助」「其他扣款」列直接编辑，自动重算个税与实发
锁定工资：核对无误点「锁定」，锁定后该月工资不可再修改（防止误改）；发现计算错误需要修改时走「受控解锁」（见下）
✅ 计算公式 应发 = 基本工资 + 岗位工资 + 各项补贴 + 加班费 - 迟到扣款 - 旷工扣款 - 缺勤扣款
实发 = 应发 - 社保个人 - 公积金个人 - 个税
🔓受控解锁 v0.5.2 新增

路径：菜单「薪酬核算 → 工资计算」→ 已锁定月份的红色「受控解锁」按钮

工资锁定后发现计算错误（如社保基数算错），不必走反月结等重流程，按受控流程修正：

受控解锁：点红色「受控解锁」→ 输入启动密码 + 填写解锁原因（至少 5 个字，如"社保基数算错需要调整"）→ 确认
修改调整：该月工资恢复可编辑，可调整 / 单人重算；已有工资计提凭证自动作废（留痕不删除）
重新锁定：修改完成后点「重新锁定」，恢复保护并自动重算计提凭证
⚠️ 安全与审计 ① 密码错误 5 次会自动锁屏（与启动密码同一安全机制）；② 每次解锁（成功或密码错误）都会记入操作日志，包含月份、原因、作废凭证数，操作全程可追溯；③ 月结前必须重新锁定，否则月结体检会阻塞；④ 已纳入付款批次的工资仍不可直接修改（需先作废批次），已正式月结的月份绝对冻结（请走反月结）。

🧾发票管理

路径：菜单「票据报销 → 发票管理」

上传发票：点「上传发票」→ 选择 PDF / JPG / PNG 文件 → 自动调用百度 vat_invoice OCR

归档：发票原图自动加密保存到 app_data_dir/invoices/{月份}/
ℹ️ 支持的发票类型 增值税普通发票 / 专用发票 / 全电发票（含 PDF 直传，无需手动转图片）/ 电子发票（铁路客运发票未来扩展）

新建报销单：填写报销人、报销事由、报销金额
关联发票：从发票库勾选多张发票纳入本次报销
提交审批：状态变为「待审批」，等待财务审核
财务审批：审核通过后状态变为「已审批」

月结与付款
付款批次统一管理 + 正式月结 + 反月结
💳付款批次

路径：菜单「薪酬核算 → 付款批次」

统一管理工资代发 + 报销付款两种场景：

💼
工资批次
从已锁定工资结果生成；自动带出收款人账号、开户行；导出银行代发 Excel
📑
报销批次
从已审批未付款报销单生成；标记已付款后自动同步报销单付款状态

批次状态流转：

草稿（draft）：刚生成，可修改
已导出（exported）：导出 Excel 准备发银行
已付款（paid）：银行确认付款完成
作废（void）：错误批次可作废，释放引用
✅正式月结

路径：菜单「工作台 → 月结工作台」

选择月份：月份选择器切换到需要关账的月份
体检：点「体检」按钮，系统自动检查 8 项异常（未算工资、未锁工资、未付款批次、未匹配流水、超预算、未审批报销、重复金额、异常考勤）
处理阻塞项：blocking 类型异常必须先处理才能关账；warning 类型可保留
正式月结：所有阻塞项处理后点「正式月结」→ 输入备注 → 该月所有数据锁定
导出月结包：点「导出月结包」生成 Excel 压缩包，含月结报告、工资明细、银行代发、发票清单、报销清单、付款批次
⚠️ 月结后不可修改 正式月结后，该月的工资 / 考勤 / 发票 / 报销 / 付款都不可修改。如需调整必须先「反月结」（需填写原因，记入操作日志）。

银行流水匹配
替代手工逐笔对账
🏦银行流水

路径：菜单「薪酬核算 → 银行流水」

导出银行流水：从企业网银导出 CSV 或 Excel 流水（含日期、摘要、对方户名、账号、收入、支出、余额）
导入流水：点「导入流水」→ 选择文件 → 自动解析字段映射
自动匹配：系统按金额一致 + 月份一致 + 已付款批次 + 摘要文本加分，自动一对一匹配
人工补对账：未自动匹配的流水可手工选择对应付款批次（金额必须一致）
忽略流水：非付款相关的流水（如手续费、利息）可标记为「忽略」
生成凭证：未匹配流水也可选科目直接生成入账凭证（如手续费计财务费用、利息收入冲财务费用），计入当月现金流量表
月结检查：存在已付款但未匹配银行流水的批次时，月结体检会阻塞
ℹ️ 不做网银直连 本工具不集成银行 API。所有流水都通过文件导入，确保与企业内部财务系统隔离，零网络风险。

预算与财务分析
从看数到发现问题
📊财务分析

路径：菜单「工作台 → 财务分析」

多维度展示月度财务数据：

  • 部门费用统计：按部门汇总工资 + 报销 + 发票费用
  • 员工费用排行：单人累计费用 Top N
  • 月度对比：环比 / 同比趋势图
  • 预算执行：实际发生 vs 预算，执行率进度条 + 超预算标红

🧠自动记账：业务发生即生成凭证

路径：菜单「财务管理 → 记账凭证」

不需要手工做账。以下业务发生时，系统自动生成借贷平衡的记账凭证：

业务动作自动生成的凭证
工资锁定借 费用科目（按部门映射，默认管理费用）／贷 应付职工薪酬
付款批次标记已付款借 应付职工薪酬（或 其他应付款—报销）／贷 银行存款

发票登记（未挂报销单）借 费用 + 进项税额 ／贷 其他应付款
银行流水选科目入账如手续费：借 财务费用 ／贷 银行存款
查看凭证：按月筛选，来源类型中文标签（工资计提 / 工资代发 / 报销计提 / 报销付款 / 发票入账 / 银行流水）
展开分录：点击行展开查看借方 / 贷方明细与摘要
自动作废：源单据解锁、批次作废、反审批时对应凭证自动作废（留痕不删除）
ℹ️ 已入账的流水不能再匹配付款批次 已生成入账凭证的银行流水，人工匹配与自动匹配都会被拒绝，避免银行存款被重复冲减。如需匹配，先取消流水匹配释放凭证。

常见问题
出纳使用最高频的问题与解答
忘记启动密码怎么办？
锁屏界面点「忘记密码？」
① 恢复码 Tab：粘贴首次设置时抄写的 24 字符恢复码 + 设新密码
② 安全问题 Tab：回答初始化时设置的安全问题 + 设新密码

注意：5 次密码错误、3 次恢复码错误、3 次安全问题错误会自动锁定。
SmartScreen 蓝色拦截怎么办？
这是 Windows 对未签名应用的默认警告，应用本身没有病毒。处理：
① 点蓝色弹窗中的「更多信息」
② 点「仍要运行」
③ 安装程序正常启动
应用启动后白屏怎么办？
通常是 WebView2 运行时缺失或显卡驱动兼容问题。排查：
① 升级到最新版 Edge / WebView2 Runtime
② 更新显卡驱动
③ 查看 %TEMP%\salary-desktop-startup.log 启动诊断日志
详细指南见 docs/troubleshooting-white-screen.md
如何把数据从一台电脑迁移到另一台？
① 在旧电脑「数据安全」→ 备份（建议勾选加密）→ 拷贝备份包到新电脑
② 新电脑安装应用 → 启动 → 设置同样的启动密码（恢复码可不同）
③ 「数据安全」→ 恢复 → 选择备份包 → 等待恢复完成
④ 重启应用
月结后发现错误怎么办？
菜单「月结工作台」→ 找到该月 → 点「反月结」→ 填写反月结原因（必填，会记录到操作日志）→ 该月数据恢复可编辑 → 修改后再次「正式月结」。

反月结操作会留痕，建议月结前充分核对。
财务报表打开全是 0 怎么回事？
两种情况属正常：
① 还没录期初余额：先到「财务管理 → 科目表 → 期初余额」选启用月逐科目录入（借贷必须平衡）；
② 看的月份早于启用月：启用月之前的月份报表为空。从启用月开始，工资锁定、报销审批、付款等业务会自动生成凭证，报表随之有数。

历史发票不会自动补凭证，需要从启用月正常使用开始积累。
凭证能不能手工修改或补录分录？
不能。本工具定位为自动记账：凭证全部由业务动作自动生成、自动作废，不提供手工凭证入口，避免账实不符。

想调整某笔业务的入账科目：① 费用类 → 在「科目表」维护费用类型映射；② 部门工资 → 维护部门映射；③ 银行流水 → 取消后重新选科目生成。
OCR 识别失败怎么办？
① 网络问题：百度 OCR 需要联网，检查代理 / 防火墙
② Token 过期：系统会自动刷新一次；仍失败到「OCR 识别中心」重新配置 API Key
③ 图片质量差：建议扫描件而非手机拍照；PDF 直接传，不用截图
④ 切换本地 PaddleOCR：完全离线，准确率略低但稳定
如何让某个员工不算工资？
员工管理 → 编辑该员工 → 状态改为「离职」或「停薪」→ 该员工不会被纳入月度工资计算。
离职员工的历史工资记录保留，方便查询和审计。
导出 Excel 后金额是星号怎么办？
这是因为当前处于「敏感数据脱敏」状态。两种处理：
① 保持脱敏导出：导出文件也是星号（适合不希望被他人看到真实数字的场景）
② 明文导出：先在任意小眼睛处输启动密码解锁 → 等待 5 分钟 → 期间导出 Excel 即为明文
身份证号 / 工资金额显示星号怎么办？
这是默认脱敏行为。点击字段右侧的小眼睛图标 → 输入启动密码 → 全应用解锁 5 分钟，期间所有 SensitiveText 显示明文。5 分钟后自动恢复脱敏。
数据库可以放 U 盘 / 网盘吗？
不建议。SQLite + WAL 在 U 盘 / 网盘上可能因同步问题导致数据损坏。
推荐：本地硬盘 → 定期「数据安全 → 备份」到 U 盘 / 网盘（加密备份包）。
应用能在 Mac / Linux 上用吗？
官方发布 Windows 64 位安装包。Mac / Linux 用户需要自行从源码编译（需要 Rust + Node + 系统 WebKit 依赖）。
建议：Windows 真机或虚拟机使用，保证最佳兼容性。
