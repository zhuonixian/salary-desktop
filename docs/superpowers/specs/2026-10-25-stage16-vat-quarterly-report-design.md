# 第十六阶段设计：增值税申报辅助——小规模纳税人季度申报表

日期：2026-10-25
状态：待审阅
基线：第十五阶段已交付（后端 410 测试）
路线图：`docs/superpowers/plans/2026-10-25-roadmap-v0.11-iterations.md`（迭代 2）

## 1. 背景与目标

办税落地（stage10 方向）的自然延伸：小规模纳税人按季申报增值税，但目前销项数据只散在台账里，季度申报前用户要手工加总。第十六阶段提供**增值税季度申报辅助表（小规模纳税人适用）导出**：按季度聚合销项发票，按征收率分组，附附加税费参考计算与账证勾稽提示。

定位是**辅助预填表**（同 stage10 扣缴端模板口径），不冒充税局官方格式；表头注明"以电子税务局当前申报表为准"。

## 2. 取数与计算口径

- **数据源**：`invoices` 中 `direction='output'` 且 `status != 'void'` 且 `belong_month` ∈ 季度三个月（Q1=01-03 … Q4=10-12）；负数票（红字冲减）一并计入合计
- **征收率分组**：rate = tax_amount / amount（amount=0 跳过分组直接归"免税/零税额"）；按容差 0.4pp 归并最近档 {1%、3%、5%}，税额=0 归"免税/零税额"，其余归"其他"
- **应纳税额** = 当季销项税额净合计（小规模无进项抵扣；进项不参与本表）
- **附加税费参考**（法定口径，仅供核对）：城建税 7%、教育费附加 3%、地方教育附加 2%，基数=应纳税额；表头注明属地费率差异与"六税两费"减半等优惠政策需自行核对
- **勾稽提示**：2221（应交税费—应交增值税/销项）当季有效凭证净贷方（credit−debit）vs 台账税额合计，差异绝对值 > 0.01 时在汇总表尾输出提示行
- **数据稳定性提示**：季度内未正式月结（month_closes.status != 'closed'）的月份列表写入表尾提示；**不设硬门禁**（申报截止次月 15 日本就早于月结节奏）

## 3. 交付物

### 3.1 Excel 导出 `export_vat_quarterly_report(year, quarter, path)`

- Sheet1「申报辅助表」：纳税人信息（company_name / taxpayer_id，缺省提示补填）→ 税款所属期 → 按征收率分组的销售额/税额（1%/3%/5%/免税/其他 + 合计）→ 应纳税额 → 附加税费三行参考计算 → 勾稽与未月结提示区
- Sheet2「销项明细」：归属月、发票代码/号码、开票日期、购买方与税号、不含税金额、税额、价税合计（与销项台账口径一致，含核销两列）
- 校验：quarter ∈ 1-4；当季无销项数据报错（同销项台账空数据口径）
- 留痕 `export_vat_quarterly_report`；文件名默认 `YYYY年第Q季度_增值税申报辅助表.xlsx`

### 3.2 前端

- 导出中心「税务申报模板」区新增卡片「增值税季度申报辅助表（小规模）」：年份 InputNumber + 季度 Select（一二三四季度）→ 复用 `handleTemplateExport` 保存对话框流程
- api 封装 `exportVatQuarterlyReport(year, quarter, path)`

## 4. 测试策略

- 季度月份映射（Q1-Q4 边界）
- 聚合：跨月多票合计、void 排除、负数票冲减、空季度报错
- 征收率分组：3%/1%/5%/免税/其他（含容差边界 2.6%、3.4%）
- 附加税费计算与四舍五入（分位）
- 勾稽：2221 凭证净贷方与台账税额一致/不一致两态
- 回归：410 存量测试全绿

## 5. 不做范围（未来增强池）

- 一般纳税人申报表（销项-进项-应纳税额抵扣链，数据已备但表式复杂，等用户需求）
- 附加税费费率可配置与减半优惠自动计算（政策时效性强，避免伪精确）
- 预缴、即征即退、免税销售额细分（不动产 5% 等）专列
- 申报表官方格式对齐（税局模板更新频繁，辅助表口径即可）
