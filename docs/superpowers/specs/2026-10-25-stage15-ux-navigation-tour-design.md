# 第十五阶段设计：上手体验——导航收敛与页面引导

日期：2026-10-25
状态：待审阅
基线：第十四阶段已交付（后端 410 测试，无后端变更）

## 1. 背景与目标

体验债两项（评估报告 P2）：

1. **导航过载**：31 个菜单叶子挂在 8 个一级分组，"资金出纳"一组 9 项远超 7±2 认知负荷；用户找"票据台账/现金盘点"需要在长列表里扫。
2. **复杂页面零引导**：Top5 复杂页（银行对账 1553 行 / 收付款单 1458 行 / 票据台账 1403 行等）是多步流程页，无 Tour、无帮助入口，全靠摸索。

第十五阶段（纯前端）：**分组重排（每组 ≤4）+ 复杂页面操作指引 Tour（4 页）**。

## 2. 导航收敛（15A）

菜单数组重组（路由与 key 全部不变，仅分组归属调整）：

| 原分组 | 新分组 |
|---|---|
| 票据报销（3） | **票据与报销**（4）：+票据台账 移入 |
| 资金出纳（9） | **资金收付**（4）：资金账户 / 收付款单 / 付款批次 / 银行对账 |
| — | **资金台账**（4）：资金日记账 / 应收台账 / 借款备用金 / 现金盘点 |

其余分组不动。结果：9 组 + 安全中心，每组 ≤4。动线语义：票据与报销（票进来）→ 资金收付（钱出去/对账）→ 资金台账（账簿勾稽）。

联动面（已核对，全部分组无关，不需改动）：`menuPathToGroupKey` 动态生成、`gateMenuItems` 操作人门禁按路径、openKeys 展开逻辑按组 key 动态、折叠 popup 行为。手册菜单速查表需同步重写（阻断项，防文档失真）。

## 3. 页面引导 Tour（15B）

- **共享组件 `src/components/PageTour.tsx`**：antd `Tour` 封装；props `{ storageKey, steps, reopenTick }`
  - 首次进入自动弹出：`localStorage['tour:${storageKey}']` 非-done 时开启；关闭（任意途径）写 done
  - `reopenTick` 递增触发重新打开：页面 header「指引」按钮复看
  - 步骤锚点用 `data-tour="xxx"` CSS selector；无匹配元素时 antd 自动居中展示，不依赖 DOM 也安全
- **接入 4 页**（复杂度 Top5 内的多步流程页）：
  1. 银行对账 BankTransactions：导入流水 → 流水状态 → 自动匹配/手工核销 → 余额调节表
  2. 收付款单 FundDocuments：新建单据（收/付/转/借）→ 审批留痕时间线 → 冲正红字 → 加密附件
  3. 票据台账 NotesInstruments：登记（收/开两向）→ 状态机流转（背书/贴现/托收/兑付）→ 凭证联动 → 红字冲正
  4. 记账凭证 Vouchers：来源筛选 → 自动凭证与业务联动 → 手工录入（收/付/转+资金辅助校验）→ 作废与月结保护
- 每页 3-5 步，文案与手册对应章节口径一致；按钮统一放 page-header-actions（「指引」+ QuestionCircleOutlined）
