# 第十三阶段设计：记账完整性——固定资产与手工凭证

日期：2026-10-14
状态：待审阅
基线：第十二阶段已交付（后端 390 测试）

## 1. 背景与目标

纯业务驱动记账在两类场景断链：**固定资产**（购置/折旧/处置是小微账上最常见的长期资产业务，目前无处安放）与**手工凭证**（摊销、暂估、股东往来、更正等无模板业务）。第十三阶段补齐记账完整性：

- 手工凭证：收/付/转三式录入，复用凭证引擎与资金辅助核算校验
- 固定资产：登记（购置凭证）→ 按月直线折旧（批处理凭证）→ 处置（清理凭证），台账与月结联动

零外联不变；月结保护全链路生效。

## 2. 手工凭证（13A）

- 命令 `create_manual_voucher(data)`：voucher_kind ∈ 收款凭证/付款凭证/转账凭证；行由用户编辑（account_code 借贷金额摘要 fund_account_id）
- 校验：月份开放；≥2 行且至少一行有金额；借贷合计平衡（容差 0.005）；收/付凭证必须含资金科目（1001/1002/1012）行且该行带 fund_account_id（对齐 bank_manual spec 4.7）；转账凭证资金科目行若存在同样必须带辅助
- source_type 'manual_voucher'（vouchers CHECK 扩展）；作废 `void_manual_voucher`（月结保护）
- 查询复用既有 get_vouchers（source_type 透出）

## 3. 固定资产（13B）

### 3.1 表

- `fixed_assets`：asset_no（ZC+日期+序号）、名称、类别（房屋建筑物/机器设备/运输工具/电子设备/其他）、购置日、归属月、原值、残值率（默认 5%）、折旧年限月数、费用科目（默认 6602，可选 5101/6601）、状态（in_use/depreciating/disposed）、处置字段（处置日/处置收入）
- `fixed_asset_depreciations`：asset_id、month、amount、voucher_id，UNIQUE(asset_id, month)

### 3.2 业务

- **登记**：生成购置凭证——借 1601 原值 / 贷 counter_account（用户选：资金科目须带辅助，或应付类）；月结保护
- **月度折旧** `run_asset_depreciation(month)`：对全部 in_use 且未提满、购置月 < 目标月的资产，月折旧 = 原值×(1−残值率)/年限（2 位；末月尾差补齐）；每资产一行折旧记录，**按月聚合一张凭证**（借按费用科目分组 / 贷 1602 合计）；重复执行幂等（已有记录跳过）；月结保护
- **处置**：状态 → disposed，终止后续折旧；生成清理凭证——借 1602 累计折旧已提额 / 借或贷 6711|6301 处置净损益 / 贷 1601 原值；处置收入>0 时另加收款资金行（须带辅助）；月结保护；已提折旧以 active 凭证口径回查
- **台账** `get_fixed_asset_ledger`：原值/累计已提/净值/月折旧/剩余月数，筛选关键字与状态；导出 Excel
- **月结检查**：当月存在应折旧资产但无折旧记录 → warning（不阻断，跳转资产页）

### 3.3 凭证 source_type

'asset_purchase' / 'asset_depreciation' / 'asset_disposal' —— vouchers CHECK 一次性扩展（stage13 重建，模式同 stage12）。

## 4. 测试策略

手工凭证：平衡/行数/资金辅助校验、收付转三类、作废与月结拦截。
固定资产：登记凭证、折旧计算（正常/尾差/提满跳过）、幂等重跑、聚合凭证借贷平衡与分组、处置凭证与净损益方向、月结拦截与 warning、导出。

## 5. 不做范围（未来增强池）

- 加速折旧/双倍余额递减/年数总和法（小企业准则常用直线法即可）
- 减值准备、在建工程转固、融资租入
- 找回密码命令补全与自动备份（独立排期，见路线图安全债）
- 凭证打印（独立立项）
