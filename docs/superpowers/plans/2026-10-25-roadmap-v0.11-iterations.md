## 需用户拍板的决策项（不自主执行）

1. **v0.10.0 发版执行**：验收清单（49+4 项，A/B/C 分级）需 Windows/macOS 真机 → 打 tag → Actions 构建 → 网盘上传 → 手册下载链接更新。
2. **自动更新通道**（P1）：Tauri updater 需生成 minisign 签名密钥并决定 endpoint（GitHub Releases latest.json vs 网盘静态页）；"零外联"原则是否为更新检查开例外（或仅手动"检查更新"按钮）。密钥生成与保管需用户参与。
3. **代码签名证书**：OV 证书（约 ¥2000/年）对 SmartScreen 转化的收益决策；需采购。
4. **多账套支持**（拓展方向）：大架构项（账套切换 UX、数据目录隔离、代账交接导出），需先出独立 spec 评审。

## 优先级依据

- stage15 先行的理由：31 页单级导航+复杂页零引导是当前最大体验债，纯前端可自主交付，且不阻塞发版（发版日可与真机验收并行）。
- 增值税申报紧随：stage10 办税方向的自然延伸，销项/进项数据已齐，用户付费意愿最强。
